## Important decisions worth remembering

- **The AI never invents facts.** Every tool checks its own output in code afterwards and throws the
  result away rather than quietly fixing it. This is the rule the whole workspace is built on.
- **The AI cannot see images.** The alt text tool is honest about this rather than pretending
  otherwise. Do not add wording that suggests it inspects pictures.
- **Alt text is review-only.** Images have nowhere to store alt text yet, so the tool shows a result
  to copy rather than saving anything. A place to store it would be a separate decision.
- **Nothing is saved automatically.** Every tool from today produces something to read and copy. No
  page, image, or record is created or edited behind the user's back.
- **Ownership is always re-checked on the server.** What the browser sends is treated as a
  suggestion, never as permission.
- **Competitor analysis only reads pages it is allowed to read**, respects each site's rules, and
  refuses unsafe web addresses before fetching anything.
- **No made-up numbers anywhere.** The platform has no ranking, traffic or backlink data, so no tool
  displays any.
